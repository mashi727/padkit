# lint の診断コード

`padkit lint` と `skill/scripts/spd_lint.py` は同じ規則を使う（後者は src から生成）。
E900 / E901 は padtools_ts を呼べる `padkit lint` だけが出す。

終了コード：error があれば 1。`--strict` では warning でも 1。info は常に 0。

## error — 図が黙って壊れる、または描けない

| コード | 内容 | padtools_ts の挙動 |
|---|---|---|
| E001 | スペースで字下げしている | 終了コード 0 で入れ子が全部消える |
| E002 | タブとスペースが混在 | 深さ 0 の箱に化ける、または見当違いのエラー |
| E103 | 未知の命令（`:ifx` など） | 前方一致する命令として読み、子を捨てることがある |
| E104 | 字下げが 2 段以上飛ぶ／先頭行が字下げされている | エラー |
| E105 | `:terminal` / `:comment` / `:switch` に子ブロック | エラー |
| E106 | 処理ボックスの 2 文字目が `#` | 次の行を同じ箱に取り込む（終了コード 0） |
| E107 | 引数が必要な命令に引数がない | エラー |
| E108 | `:else` に引数がある | エラー |
| E109 | `:else` の行にコメント | else 側を丸ごと捨てる（終了コード 0） |
| E110 | `:else` の直前の兄弟が `:if` でない／二つ目の `:else` | エラー |
| E111 | `:case` の直前の兄弟が `:switch` / `:case` でない | エラー |
| E112 | `:case` の値が重複 | エラー |
| E115 | 最後の文が、字下げされた 1 文字の処理ボックス | その箱が消える（終了コード 0） |
| E900 | padkit の解析と padtools_ts の AST が食い違う | 未知の黙殺。差分の位置を表示する |
| E901 | padkit は通したが padtools_ts がエラーにした | — |

E900 は「書いたとおりの構造」を padkit 自身のパーサで組み、padtools_ts の
`--export-ast` と比較して出す。上の個別規則をすり抜けた未知の不具合への最後の防壁である。
個別規則に該当する入力では、まずそちらが出るので E900 は出ない。

## warning — 粒度の問題（`--strict` で失敗）

| コード | 内容 | 閾値 |
|---|---|---|
| W201 | ネストが深すぎる | 深さ 5 超 |
| W202 | ボックスの文字が長い | 40 セル（全角 20 字）超。全角・曖昧幅は 2 セル |
| W203 | 一つの親の下に箱が多すぎる | 15 超 |
| W204 | 箱が多いのに `:call` が無い | 60 超 |

## info — 講評の材料

| コード | 内容 |
|---|---|
| I301 | `:while` / `:dowhile` が一つも無い |
| I302 | `:else` の無い `:if` |
| I303 | `:terminal` の後に、同じブロックでまだ処理が続く |
